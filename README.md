## **Описание:**
Дипломный проект созданный при обучении в техникуме. 
После выпуска был использован для попытки самостоятельного изучения организации структуры кода по паттерну MVC (Model-View-Controller).

## **Статус:**
На данный момент находится в статусе переписывания. Для формирования представления об изначальной структуре кода программы можно ознакомиться со старым [курсовым проектом](https://github.com/sk-mm27/Coursework).

## **Функционал:**
В проекте реализовано 15 функций и разделение пользователей на 2 роли отличающиеся по возможностям. При использовании [приложенной базы данных](https://github.com/sk-mm27/DiplomaProject/blob/master/DiplomaProjectDataBase.bacpac) для тестирования имеется пользователь с логином 1 и паролем 1 с ролью администратора.
