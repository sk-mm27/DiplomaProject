## **Описание:**
Дипломный проект созданный при обучении в техникуме. 
После выпуска был использован для попытки самостоятельного изучения организации структуры проекта по паттерну MVC (Model-View-Controller).

## **Статус:**
На данный момент находится в статусе переписывания.

## **База данных:**
Для создания базы данных использовался Microsoft SQL Server.
